Executive Summary

North Valley Junk Removal has strong trust signals — real reviews, a clear service catalog, and a genuinely compelling community-cleanup story. However, the homepage has structural and on-page SEO problems that are limiting its ability to rank for high-intent local searches like "junk removal North Phoenix", "hot tub removal Cave Creek", or "appliance removal Anthem AZ".

Most issues stem from the site being built on GoDaddy's Website Builder, which auto-generates structural HTML and limits how much can be controlled. The highest-impact fixes (title tag, meta description, image alt text, business schema) can be addressed within the platform. Several structural problems (duplicate H1, broken heading hierarchy, generic schema type) are platform-imposed.

Issues Found

Critical

1. Two <h1> tags on a single page. Both H1s say "North Valley Junk Removal". Google expects exactly one H1 representing the primary topic of the page. This is a structural problem caused by the GoDaddy template.
2. Title tag is brand-only — no keyword, no location. Current: North Valley Junk Removal (25 chars). The title tag is the single strongest on-page ranking signal, and yours contains zero keywords beyond the brand name.
3. No canonical tag. The homepage can be reached at / and /home (your og:url points to /home). Without a canonical, Google has to guess which to index, which can split signals.
4. Heading hierarchy skips levels. Page goes H1 → H2 (Reviews) → H4 (Our Story, Our Commitment, etc.). No H3 tier exists. Skipping H3 weakens semantic structure for both Google and screen readers.
5. Schema NAP is unusable. Your LocalBusiness schema has streetAddress: "Cave Crk" (abbreviated, typo'd), no city, no state, no postal code, and no phone number. This is the data Google uses to place you in the local map pack — currently, none of it is usable.

High Priority

6. 8 of 11 images have no alt text. Worse, the alt text that does exist on your logo says "North Valley Custom Hauling" — wrong business name entirely.
7. Meta description is weak and missing key info. Current description lists services but omits your phone number, service area, and any value proposition. This is the snippet potential customers see in Google before clicking.
8. No phone number in schema markup. For a service business where calls/texts are the primary conversion path, omitting telephone from schema is a significant local-SEO miss.
9. Zero geographic targeting in metadata. Title, meta description, H1, URL, and most body content contain no location signals. "North Phoenix" and "Desert Hills" appear once each in body copy. For a service-area business, this is the largest single missed opportunity.
10. Schema type is too generic. Currently uses LocalBusiness. Should be the more specific JunkRemovalService or at minimum HomeAndConstructionBusiness. Also missing: priceRange, areaServed, email, sameAs (Instagram), and a service catalog.
11. Open Graph image is missing description. When someone shares your link on Facebook, LinkedIn, or via SMS, the preview will show the brand name as the description because og:description is not set.

Medium Priority

12. Twitter card description is just the brand name. twitter:description="North Valley Junk Removal" — wasted opportunity for a value-rich snippet.
13. Schema @id is an invalid URL. Currently http://430a2e70.0836.48c9.938a.20bc73abcb7e.com, which is an internal GoDaddy identifier, not a valid web address. Should reference your canonical homepage with a fragment, like https://northvalleyjunkremoval.com/#business.
14. og:image and schema image use http:// Your site is HTTPS but image URLs in metadata use HTTP. Mixed-protocol references can trigger browser warnings on some platforms.
15. Limited E-E-A-T signals. No owner/team bio with names, no licensing/insurance proof, no certifications, no "About the owner" section. Trust signals are weak for an in-home service business.
16. Service subpages may not have homepage-level internal links. Services (Appliance Removal, Hot Tub Disposal, etc.) appear in the menu but may not be linked from the homepage body content with descriptive anchor text.

Low Priority

17. Page weight (176 KB HTML) is reasonable. No action needed.
18. Duplicate logo rendered in markup (mobile + desktop swap pattern). Minor DOM bloat, common on GoDaddy. Not actionable without leaving the platform.
19. Only one substantive external link (Instagram). Linking to authoritative sources (Maricopa County waste disposal regs, recycling partners) would strengthen E-E-A-T.
